# Brew & Bean ☕

Brew & Bean is a web-based coffee shop project developed using PHP, MySQL, HTML, CSS, and JavaScript.

## Features
- Browse coffee products and categories.
- View product details.
- Search and explore products.
- Add products to the shopping cart.
- User-friendly interface with language switching.

## Technologies Used
- PHP
- MySQL
- HTML5
- CSS3
- JavaScript

## Note
This project requires a PHP server and a MySQL database to run locally.
